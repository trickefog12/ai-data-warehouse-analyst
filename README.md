# 📊 AI-Powered Warehouse Data Analyst

An automated data pipeline that cleans, processes, and visualizes logistics data using **Python** and **Pandas**. 

## 🚀 Overview
This project demonstrates **Data Engineering** and **Applied Analytics** skills by taking raw, "dirty" warehouse data and converting it into actionable business insights.

## 🛠️ Tech Stack
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn

## 📈 Key Features
- **Data Cleaning:** Automated handling of missing values (Imputation) and data sanitization.
- **Reporting:** Automatic calculation of Revenue per product and Total Units sold.
- **Visualization:** Generates professional-grade charts for business presentations.

## 🏃 How to Run
1. `pip install -r requirements.txt`
2. `python generate_data.py` (to create raw data)
3. `python analyzer.py` (to process and visualize)
